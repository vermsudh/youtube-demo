8) ![1790569294921](image/learning_crud/1790569294921.png)
   We might encounter on this error if we try to submit the form now.
   Whenever we send a POST request to Laravel, we would need to include CSRF token in order to send it through.

   A **Laravel CSRF token** is  =a unique, secret value generated by the application to protect against **Cross-Site Request Forgery (CSRF) attacks**= . It ensures that the authenticated user is the one actually making state-changing requests (like `POST`, `PUT`, `PATCH`, or `DELETE`) to the application. If a request is missing the token or contains an incorrect one, Laravel will reject it and return a **419 Page Expired** error status code.

9) Now, we would want to save all the post request to a seperate file instead of just showing 'Thank you'.
   Now, we have to make changes in the controller.
   In Laravel, a **Controller** is  =a PHP class that acts as the intermediary between your HTTP requests and your application logic= . Instead of putting all your request-handling code directly inside route files (like `web.php`), you group related logic into controllers to keep the codebase clean, organized, and compliant with the Model-View-Controller (MVC) architecture.
